# Rules: pesquisa

> **Editable rules.** The skill reads this file first, and it overrides the defaults in SKILL.md.
> These are starting assumptions: add, change or delete rules freely. One rule per bullet.
> Remove a whole section if you do not want it.

## Sources
- Prefer primary and official sources: IBGE, prefeituras, museums, universities, national archives, newspapers of the period.
- Wikipedia is only a starting point. Confirm key facts in at least **2 independent sources**.
- Every fact gets a link and the access date. No link means `⚠️ verificar`.
- Without web access, say so at the top of the note and mark every fact `⚠️ verificar`.

## Names
- Give at least **8 options** per request, each with origin/meaning and why it fits the era, region and social class.
- Check anachronism: the name must have been in use in that place and period.
- Avoid names of famous real people unless the author asks for them.
- Invented place names: check and say whether a real place already has that name.

## Places and periods
- Every place note has a **detalhes sensoriais** section (sounds, smells, light, textures, food).
- Include daily life (work, prices, transport, religion, leisure) for the period asked, not just today.

## Respect
- Avoid stereotypes. For Indigenous, Afro-Brazilian, Romani and other marginalized cultures, note the sensitivity and suggest a sensitivity reader.

## Limits
- Research only: don't write story scenes or dialogue.
- Keep a note to about 2 pages. Offer a deeper follow-up instead of dumping everything.

## Saving
- Check whether `pesquisa/` exists by listing the book folder itself (for example `ls`). A file search misses an empty folder.
- If `pesquisa/` already exists in the book folder, save the result there without asking, and give the file path in the reply.
- If `pesquisa/` doesn't exist, ask once before creating it. If the writer says no, return the result in the chat.
- Never overwrite an earlier result: if the file name is taken, add `-2`, `-3`, and so on.
